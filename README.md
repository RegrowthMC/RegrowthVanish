# RegrowthVanish
The purpose of this project is to act as a simplified and modernised version of [VanishNoPacket](https://github.com/mbax/VanishNoPacket), this is **not a fork** and should not be treated as one.
Whilst much of the code remains the same it is a **full rewrite** written in the coding style of the [RegrowthMC](https://github.com/RegrowthMC) projects.
If you like how much power you have over settings with permissions in [VanishNoPacket](https://github.com/mbax/VanishNoPacket) then this project is not for you, much of the permission handling is merged into a smaller number of permissions for ease of use.
